# LMS Backend

## Запуск проекта с помощью Docker Compose

1.  **Установите Docker и Docker Compose.**
2.  **Клонируйте репозиторий:**

    ```bash
    git clone [URL вашего репозитория]
    cd [имя папки репозитория]
    ```

3.  **Создайте файл `.env`** на основе `.env.example` и заполните его значениями.

4.  **Запустите проект:**

    ```bash
    docker-compose up --build
    ```

    (Используйте `-d`, чтобы запустить в фоновом режиме: `docker-compose up -d --build`)

## Проверка работоспособности сервисов

*   **Бэкенд:** Откройте в браузере `http://localhost:8000/`. Вы должны увидеть страницу Django или сообщение об ошибке (если еще не настроили маршруты). Если вы настроили Nginx, то `http://localhost/`.
*   **База данных (PostgreSQL):** Подключитесь к базе данных с помощью клиента PostgreSQL (например, pgAdmin) с использованием настроек из `.env`.
*   **Redis:** Используйте клиент Redis (например, `redis-cli`) для подключения к Redis и проверки его работоспособности.
*   **Celery:** Проверьте логи контейнера Celery (с помощью `docker logs celery`) на наличие ошибок. Убедитесь, что Celery успешно подключается к Redis.
*   **Celery Beat:** Аналогично Celery Worker, проверьте логи контейнера Celery Beat (с помощью `docker logs celery-beat`) на наличие ошибок и убедитесь, что задачи планируются.

**Ключевые моменты при использовании Poetry с Docker:**

*   **Копирование `pyproject.toml` и `poetry.lock`:**  Очень важно скопировать эти файлы *до* 
копирования остального кода проекта.  Это позволяет Docker кэшировать слои сборки, связанные с установкой зависимостей. 
Если `pyproject.toml` или `poetry.lock` не изменились, Docker будет использовать кэшированный слой, 
что значительно ускорит сборку образа.
*  **Отключение виртуальных окружений Poetry:** В Docker виртуальное окружение не нужно, 
так как Docker сам по себе предоставляет изолированное окружение.  
Отключение виртуальных окружений Poetry упрощает процесс сборки и установки зависимостей.
*  **Обновляйте `poetry.lock`:** Когда вы добавляете или обновляете зависимости с помощью Poetry, 
не забывайте обновлять файл `poetry.lock` и коммитить его в репозиторий.  
Этот файл содержит точные версии всех зависимостей и обеспечивает воспроизводимость сборки.
